# pytools 使用指南（按菜单顺序）

本文档对应 [main.py](./main.py) 当前菜单顺序，每个菜单项包含 **入口 / 逻辑 / 输出** 三段，便于理解每个功能在做什么、产出在哪。

## 启动与配置

启动：

```bash
python pytools/main.py        # 源码运行
pytools.exe                   # PyInstaller 打包后运行（cwd 必须是 exe 所在目录）
```

配置文件：`pytools/config/config.xlsx`（exe 模式下：`<exe同级>/config/config.xlsx`）。

**首次使用必做**：主菜单 `5` → `1`（初始化/修复配置表）。该步只创建缺失 Sheet、补齐表头与必要批注，**不会清空已有数据行**。

`pytools/main.py:_app_base_dir()` 决定运行目录：源码模式取 `pytools/` 父目录、frozen 模式取 exe 同级目录。所以 `output/` 和 `logs/` 也跟着 exe 走。

## 1. 时序工具

> 共同前提：所有时序功能都按 `时序提取规则` 表里的 `工作簿关键字` + `工作表关键字` 双过滤匹配源文件，再按 `行头列` / `列表头行` / `数据起止行列` / `必含列头` / `必含行头` 等参数定位数据矩形区域。

### 1.1 表头路径比对（混合）
- **菜单**：`1 → 1`
- **先配**：`全局配置` + `时序提取规则`
- **运行**：先选 1 个模板文件，再多选源文件
- **逻辑**：
  - 对每条启用规则，分别在模板和源文件上展开匹配的工作表；
  - 收集模板与源各自的"行头集合"和"列头路径集合"，做差集（按位置 + 按路径两套口径）；
  - 在源里出现但在模板里没有（或路径变形）的会进入差异表。
- **输出**：`output/compare_3_9_3_<时间戳>.xlsx`
  - Sheet `表头比对结果`：12 列，前 10 列结构对齐 `路径标准化映射` 表（可直接复制回去登记标准化），后 2 列 `源文件 / 工作表`
  - Sheet `汇总`：每源文件按位置/按路径差异计数

### 1.2 时序提取（快速精简）
- **菜单**：`1 → 2`
- **先配**：`全局配置` + `时序提取规则` + `路径标准化映射`
- **运行**：多选源文件
- **逻辑**：
  - 对每个匹配 sheet，按规则定位的矩形区域逐 cell 提取；
  - 行头/列头按 `路径标准化映射` 中的 `匹配方式`（精确/前缀/包含/正则）做归一；
  - 按 `(源文件, sheet, 数据日期, 行头路径, 列头路径, 值)` 整组去重；
  - **无匹配则不生成文件**，仅在日志里给每条规则的 `wb_miss / sheet_miss / cells` 计数。
- **输出**：`output/<时间戳>_时序提取（快速精简）.xlsx`
  - Sheet `时序提取结果`：7 列 `源文件 / 工作表名 / 规则名称 / 数据日期 / 行头路径 / 列头路径 / 数值`
  - 若规则配置了 `目标工作簿路径` + `目标工作表` 且 `启用目标写入=是`，会同时把对应行 append 到目标簿对应表

### 1.3 / 1.4 宽表汇总
- **菜单**：`1 → 3`（行头加后缀）/ `1 → 4`（行头不加后缀）
- **先配**：同 1.2
- **运行**：多选源文件
- **逻辑**：
  - 走与 1.2 相同的提取管线，但按 `(规则, 工作簿, 工作表, 数据日期, 行头路径)` 聚合，列头路径作为列名展开成宽表；
  - "行头加后缀"模式（3.9.7）：行头路径同名时追加 `_2/_3/...` 区分；不加后缀模式（3.9.8）：直接同名合并，**列冲突会计数并打印** `conflict=N`；
  - 列顺序按首次出现保留；每条规则一个 Sheet。
- **输出**：
  - 1.3 → `output/<时间戳>_宽表汇总（行头加后缀）.xlsx`，标签 `3_9_7`
  - 1.4 → `output/<时间戳>_宽表汇总（行头不加后缀）.xlsx`，标签 `3_9_8`
  - Sheet 名 = 规则名称；前 4 列固定（`工作簿名 / 工作表名 / 数据日期 / 行头路径`），其后是动态列头路径列

### 1.5 预校验
- **菜单**：`1 → 5`
- **先配**：`config.xlsx`
- **逻辑**：见 `core/precheck_399.py`。检查：必需 Sheet 是否齐全、`全局配置` 必填键（`输入目录/输出目录/日志目录`）、`时序提取规则` 列是否齐全、`列号说明` 是否能解析（`行头列 / 列表头行 / 数据起止行列` 等都按 `parse_col_spec` 处理）、`输入/输出/日志` 目录是否存在或可创建。
- **输出**：仅控制台报告，最后一行打印错误数。返回值供 CLI 退出码使用。

### 1.6 ~ 1.9 [COM] 版本
- 与 1.1~1.4 一一对应，但底层走 Excel COM（`pywin32` + `Excel.Application`/WPS `ket.Application`）：
  - 优点：能读 `.xls` / 含公式且需要刷新计算的工作簿、保留合并/格式语义；
  - 缺点：需 Windows + 安装 Excel/WPS，速度慢；
  - 未安装 `pywin32` 时打印 `[COM 不可用]` 并跳过。
- **逻辑/输出**：完全复用同名非 COM 版本的下游逻辑（`com_engine.ArrayLike` 把 COM 二维数组伪装成 DataFrame 接口），所以输出文件结构一致，只是日志名加 `_com` 后缀。

## 2. 去重工具

> 关键参考实现：`core/dedup_311.py`。重复行的判定 = 指定"键列"的字符串（`str().strip()`）逐列等值；键全空的行不参与去重。

### 2.1 按批注检查重复
- **菜单**：`2 → 1`
- **运行**：选 1 个工作簿
- **逻辑**：
  - 扫描每个 sheet：仅 A1 单元格批注包含"源数据"的 sheet 参与；
  - 键列 = 表头第 1 行批注包含"标识列"的所有列；若一个都没有则退化为"全部已用列"；
  - 第 2 行起逐行算 key，重复行用 **红色填充** 标记（不删数据），每行涂的是 1 ~ 已用列数。
- **输出**：原文件**就地保存**（红色高亮）；日志记录每个 sheet 的重复条数。

### 2.2 按批注删除重复
- **菜单**：`2 → 2`
- **运行**：选 1 个工作簿
- **逻辑**：同 2.1 的 sheet/键列识别规则，但保留首次出现、删除其余重复行（自下而上 `delete_rows`）。
- **输出**：原文件就地保存；日志记录每 sheet 删除行数。

### 2.3 / 2.4 / 2.5 按配置 检查 / 删除 / 去重追加
- **菜单**：`2 → 3 / 4 / 5`
- **先配**：`去重追加数据配置`（列：`是否启用 / 源数据工作簿 / 源数据工作表 / 标识列序号 / 目标工作簿 / 目标工作表 / 执行模式 / 备注`）
- **逻辑**：
  - 不再依赖批注；从配置读 source_wb/source_ws + 键列序号；
  - 2.3 检查、2.4 删除：行为同 2.1/2.2，但作用对象由配置指定；
  - 2.5 去重追加：先在源里去重，再把幸存行 append 到目标 sheet，键已存在于目标里的不再追加。
- **输出**：源/目标工作簿就地保存；2.5 还会在日志里记录"新增 N 行 / 重复跳过 M 行"。

### 2.6 按配置预校验
- **菜单**：`2 → 6`
- **逻辑**：只读校验。检查每条配置项的源/目标路径是否存在、sheet 是否存在、键列序号是否在已用列范围内、目标 sheet 表头是否能匹配。
- **输出**：控制台报告。

## 3. 打印工具

> 关键参考实现：`core/print_310.py`。所有"打印"功能其实是**生成新工作簿**：把指定 sheet/区域抽取出来、合并到一个新文件、设置 `PrintArea / FitToPagesWide / FitToPagesTall / 打印方向`。

### 3.1 按批注打印（保留源格式）
- **菜单**：`3 → 1`
- **运行**：多选源文件
- **逻辑**：
  - 扫源文件每个 sheet，A1 批注里出现 `打印区域 #N`（N 不写默认 1）的进入候选；
  - **逐 sheet 复制**到新工作簿，连带格式、合并、列宽、批注一起 `copy()`，但只保留批注定义的打印区域；
  - 同一源文件的多个目标区域按 `#1 #2 #3` 顺序生成多个 sheet。
- **输出**：每个源文件一个 `output/<时间戳>_按批注打印（保留源格式）.xlsx`（同名时追加 `_1/_2`）。

### 3.2 按批注打印（快速复制）
- **菜单**：`3 → 2`
- **运行**：多选源文件
- **逻辑**：同 3.1 的 sheet/区域识别规则，但只复制**值**（不复制格式/合并），速度大约 5~10×。
- **输出**：每源文件一个 `output/<时间戳>_按批注打印（快速复制）.xlsx`。

### 3.3 按配置打印（执行全部模式）
- **菜单**：`3 → 3`
- **先配**：`打印配置` + `全局配置`
- **逻辑**：
  - 配置每行声明 `打印模式 / 源工作簿 / 源工作表 / 源工作表打印区域 / 目标工作簿 / 目标工作表 / FitToPagesWide / FitToPagesTall / 打印方向 / 备注`；
  - 按 `打印模式` 分流到 3.1 / 3.2 的复制逻辑，最终统一写到 `目标工作簿/目标工作表`。
- **输出**：写到配置指定的 `目标工作簿`（不在 output 下，而是配置指明的路径）；冲突则触发 `_save_with_suffix_fallback` 自动 `_1/_2`。

### 3.4 按配置打印预校验
- **菜单**：`3 → 4`
- **逻辑**：只读校验配置每行：源/目标路径存在、源 sheet 存在、`打印模式` 合法、`FitToPages*` 数值合法、`打印方向` ∈ {横向, 纵向, 空}。
- **输出**：控制台报告。

### 3.5 ~ 3.8 [COM] 版本
- **3.5 / 3.6 / 3.7**：同 3.1 / 3.2 / 3.3，但用 Excel COM 复制（保真度更高，能携带非 openpyxl 支持的格式）。
- **3.8**：在 3.7 完成后，对每个目标 sheet 调 COM `ExportAsFixedFormat(xlTypePDF)`，按 `FitToPages*` + `打印方向` 设置好打印参数后导出 PDF。
- **输出**：3.5/3.6 落到 `output/`；3.7 落到配置中的目标簿；3.8 在目标簿同目录生成 `.pdf`。

## 4. 转换工具

参考 `core/convert_33_34_35_37.py`。

### 4.1 批量重命名文件
- **菜单**：`4 → 1`
- **先配**：`重命名配置`（`简称/全称/代码/全称(代码映射)/键/值/原表名/新表名` 等列）
- **逻辑**：从配置构建三套映射 `简称→全称`、`全称→代码`、`键→值`，对每个选中文件名按所有映射做替换。
- **输出**：原地重命名（不复制）；日志列出 `旧名 → 新名`。

### 4.2 [COM] 批量 Excel 格式转换
- **菜单**：`4 → 2`
- **逻辑**：调 COM `Workbook.SaveAs`，目标格式从 `全局配置` 的 `excel目的格式` 读（默认 `xlsx`）。支持 `.xls/.xlsx/.xlsm/.xlsb/.csv` 互转。
- **输出**：每个源文件在同目录生成新格式同名文件（保留原文件）。

### 4.3 [COM] 批量 Word 格式转换
- **菜单**：`4 → 3`
- **逻辑**：调 Word COM，目标格式从 `全局配置` 的 `word目的格式` 读（默认 `docx`）。
- **输出**：同上。

### 4.4 / 4.5 批量修改 Sheet 名
- **菜单**：`4 → 4`（openpyxl，不支持 `.xls`）/ `4 → 5`（COM）
- **先配**：`重命名配置` 的 `原表名 / 新表名` 两列
- **逻辑**：对每个选中工作簿遍历 sheet，命中 `原表名` 则改为 `新表名`。冲突自动加 `_2/_3` 后缀。
- **输出**：原工作簿就地保存。

## 8. 调研选项统计

### 8.1 按题目选项比例统计 + 展示版
- **菜单**：`8 → 1`
- **先配**：`问卷统计配置`（机构名标准化复用 `重命名配置` 的 A→B 列）
- **运行**：选 1 个"按机构 × 题汇总"的输入文件（典型来源：3.2.2 按批注汇总输出）
- **逻辑**：见 `core/survey_stats.py`。
  - 按 `问卷统计配置` 首条 `是否启用=是` 的行读参数；
  - 用 `重命名配置` 把机构简称映射为全称（精确匹配 + 长简称包含匹配；未命中时按 `机构名称兜底清洗规则` 剥噪音再试一次）；
  - 按题干分组（可选拼上 `路径列列表` 作为题目前缀），从 `选项列` 解析 `[(编码, 文本)]`，从 `答案列` 识别勾选的编码集合；
  - 启发式判定单选/多选：题干或选项文本中含"多选"即视为多选。
- **输出**：默认写到 `问卷统计配置.输出目录`（留空=`output/`），生成两份：
  - `<输出前缀>_按题目选项比例统计_程序版.xlsx` — 每题每选项一行（小计/占作答比例/占勾选比例/作答机构数/勾选总次数）
  - `<输出前缀>_按题目选项比例统计_展示版_程序版.xlsx` — 每题分块，含 `选项 → 机构名单`、单选题的多选机构、未选机构、本题有效填写机构数

#### `问卷统计配置` 字段说明

> 表头已加批注，鼠标悬停可查看；批注与下表内容一致。**列定位类字段**（机构列/题目列/选项列/答案列/路径列列表）三种写法等价：列名（如 `机构`）、字母列号（如 `D`）、数字列号（如 `4`）。

| 列名 | 必填 | 默认 | 说明 |
|---|---|---|---|
| 是否启用 | 是 | — | `Y/是/1` 表示启用；程序读首条启用项 |
| 配置名称 | 是 | — | 仅日志展示用的标识 |
| 工作表名称 | 否 | 第一张表 | 输入工作簿中的目标工作表名 |
| 机构列 | 是 | — | 机构名所在列 |
| 题目列 | 是 | — | 题干所在列 |
| 选项列 | 是 | — | 选项定义所在列；每选项独占一行：`A 城商行` / `B、农商行` / `C. 其他` |

## 输出与日志

- **输出目录**：`<全局配置.输出目录>`，未配则默认 `pytools/output/`（exe 模式下：`<exe同级>/output/`）
- **日志目录**：`<全局配置.日志目录>`，未配则默认 `pytools/logs/`
- **日志命名**：`<功能编号>_<时间戳>.log`，每条日志同时进文件和 stderr（见 `core/logger.py`）
- **输出文件命名**：大多数为 `<时间戳>_<菜单中文名>.xlsx`，少数（compare）为 `compare_3_9_3_<时间戳>.xlsx`

> 排查"有运行无结果"时优先看日志：每个功能结束都会打印 `wb_miss / sheet_miss / cells / matched / conflict / saved` 等口径，对比即可定位是关键字没匹配上、规则区域没数据、还是目标写入被禁用。

## 引擎选择（pandas vs COM）

- **默认走 pandas/openpyxl**：跨平台、无外部依赖、快。
- **`[COM]` 标记的菜单**走 Excel COM（需 Windows + Excel/WPS + `pywin32`）：
  - 必要场景：处理 `.xls`、含动态计算公式、保留全部格式语义、生成 PDF；
  - 同名功能逻辑等价（`com_engine.ArrayLike` 让两套引擎共用下游计算），输出文件结构一致；
  - 未装 `pywin32` 时仅打印 `[COM 不可用]`，主菜单不会崩。
