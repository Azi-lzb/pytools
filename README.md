# pytools（通用汇总工具）

面向 Excel 场景的批处理工具，提供时序提取、去重、打印、转换、汇总和专项处理能力，支持普通模式与 COM 模式（兼容 `.xls` 等老格式）。

## 目录结构

- `pytools/`：核心源码
- `pytools_entry.py`：程序入口
- `pytools/config/config.xlsx`：配置文件
- `dist/`：打包后的可执行程序与运行目录
- `build_exe.bat`：一键打包脚本（PyInstaller）

## 运行方式

### 1) 直接运行源码

```bash
python pytools_entry.py
```

运行后按菜单选择功能：

- `1` 时序工具
- `2` 去重工具
- `3` 打印工具
- `4` 转换工具
- `5` 配置工具
- `6` 汇总工具
- `7` 一二批处理工具
- `8` 调研选项统计

### 2) 运行打包程序

进入 `dist/` 目录，直接双击或命令行运行 `.exe` 文件。

## 打包

```bash
build_exe.bat
```

默认使用 PyInstaller 生成单文件程序（`--onefile`）。

## 功能说明

### 1. 时序工具

- 表头路径比对（模板 + 多源文件）
- 时序提取（快速精简）
- 宽表汇总（行头加后缀 / 不加后缀）
- 预校验
- COM 对应版本（适配 `.xls` 等）

### 2. 去重工具

- 按批注检查重复 / 删除重复
- 按配置检查重复 / 删除重复
- 按配置去重并追加到目标
- 按配置预校验

### 3. 打印工具

- 按批注打印（保留源格式 / 快速复制）
- 按配置打印（执行全部模式）
- 按配置预校验
- COM 对应版本
- COM 打印并导出 PDF（打印预览）

### 4. 转换工具

- 批量重命名文件
- 批量 Excel 格式转换（COM）
- 批量 Word 格式转换（COM）
- 批量修改 Sheet 名（普通 / COM）

### 5. 配置工具

- 初始化/修复 `config.xlsx`
- 查看当前配置并重新读取

### 6. 汇总工具

- 按使用区域汇总（全量）
- 按批注汇总（模板 + 源文件）
- COM 对应版本

### 7. 一二批处理工具

- 拆分村镇银行数据
- 机构名称标准化
- 删除分机构表外资行
- 外汇页眉修改（普通 / COM）
- 地区总分校验
- 提取工作表数据（普通 / COM）
- 涉农贷款“比上月”修正

### 8. 调研选项统计

- 按配置统计题目选项比例
- 生成明细版与展示版结果文件

## 配置与输出

- 主配置文件：`pytools/config/config.xlsx`
- 输入/输出/日志目录由配置表控制
- 程序会按功能自动生成日志，便于追溯

## 注意事项

- COM 功能依赖本机可用的 Office/Excel COM 环境。
- 涉及文件选择时，程序会弹出选择窗口；若弹窗不可用，可手动输入路径。
- 首次使用建议先执行“配置工具 -> 初始化/修复配置表”。
